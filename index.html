How I work

Deployed beats described. Every repo has a landing page and a dashboard that reads real output. A screenshot is not a product.

A number or it did not happen. Each repo carries EVIDENCE.md with the command that reproduces every figure. Missing numbers are labelled missing.

Tradeoffs are the deliverable. Every repo documents the governing constraint, the options rejected, and what would change my mind.

Explainable or excluded. If I cannot defend a line cold, it does not go on the profile. Ownership is tracked per module in each repo.

What I deliberately do not build

  • Todo apps, weather apps, calculators, e-commerce clones
  • Another RAG chatbot, or an AI feature without a boundary
  • Any claim without the command that reproduces it
  • A tenth repository that repeats a pattern I already have
