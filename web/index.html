A portfolio that refuses to type its own numbers

Case studies for each repository, an evidence wall pulled from the repositories own EVIDENCE.json at build time, and a printable resume at /resume.html.

Built for recruiters and interviewers who would rather see evidence than read adjectives.

Evidence

Rendered from evidence.json, written by this repository when it runs. No figure on this page is typed by hand.

The problem

Portfolios drift: claims are typed by hand, go stale, and cannot be checked.

How it works

STEP 1Each repository runs make evidence and writes EVIDENCE.json with its own real numbers
STEP 2The site build script reads those files and merges them into one aggregate, refusing any entry with no source
STEP 3Pages render from that aggregate; a missing source is rendered as a refusal, never as a guess

What it does NOT do

  • No analytics or tracking
  • No framework build step - the build is one readable script
  • No invented metrics: if a repo has not measured it, the wall shows nothing

Where the numbers come from

Run make evidence and every row below is regenerated.
